## 实现过程中的发现

- 修完一批 lint 错误后要重新跑一遍 lint：`react-hooks/set-state-in-effect` 这类错误会被同一处的其他错误遮住，第一轮看不到。
- React 状态要跟随外部对象（引擎）时，用订阅回调里 `setState`，不要在 effect 主体里同步 `setState`。
- Tailwind v4 下，全局 CSS 里不在 layer 中的规则会压过所有工具类。全局样式一律写进 `@layer base` / `@layer components`；改完样式体系后在浏览器里量一个 `px-*` 的实际值。
- 并行子代理一次不超过 3 个：5 个同时跑时有一个因 429 中断且没有报告。中断的代理先检查它留下的文件再决定续跑还是接手。
- 断言“状态变了”的测试太弱：打开一个确认提示也算变了。要断言命令的实际效果。
